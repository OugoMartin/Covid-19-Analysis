# Tableau Build Guide

Connect Tableau to the cleaned CSV generated by the Python workflow.

## Data checks

- `date` → Date
- `location`, `continent` → Dimensions
- COVID metrics → Measures
- Use country-only records for country rankings.
- Use **MAX** or a latest-date approach for cumulative measures; do not SUM cumulative totals across dates.

## Worksheet 1 — Case Trend

- Columns: Date (continuous)
- Rows: New Cases 7-Day Average
- Location: Filter
- Marks: Line

## Worksheet 2 — Mortality Trend

- Columns: Date
- Rows: New Deaths 7-Day Average
- Location: Filter
- Marks: Line

## Worksheet 3 — Highest Reported Cases

- Rows: Location
- Columns: MAX(Total Cases)
- Sort descending
- Apply Top N filter after validating country coverage.

## Worksheet 4 — Deaths per Million

- Rows: Location
- Columns: MAX(Total Deaths Per Million)
- Sort descending

## Worksheet 5 — Cases vs Mortality

- Columns: Total Cases Per Million
- Rows: Total Deaths Per Million
- Location: Detail
- Marks: Circle

## Worksheet 6 — Vaccination Trend

- Columns: Date
- Rows: Vaccination Rate
- Location: Filter
- Marks: Line

## Risk-factor worksheets

Create country-level scatter plots for:
- Median Age vs Deaths per Million
- GDP per Capita vs Deaths per Million
- Hospital Beds per Thousand vs Deaths per Million
- Diabetes Prevalence vs Deaths per Million
- Human Development Index vs Deaths per Million

## Dashboard design

Build four dashboards:
1. Overview
2. Cases & Mortality
3. Testing, Vaccination & Healthcare
4. Public Health Risk Factors

Use consistent Location, Continent and Date filters where relevant. Add explanatory captions so viewers understand that correlation does not establish causation and that source coverage affects country comparisons.
